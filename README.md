# 🎓 Uni-Hub (سامانه ثبت اطلاعات دانشجویی)

یک مینی‌پروژه سریع و سبک با Node.js برای جمع‌آوری مطالبات، خاطرات و لینک‌های ارتباطی دانشجویان. این سیستم داده‌ها را دریافت کرده و به مدیر سیستم اجازه می‌دهد خروجی آن‌ها را به صورت مستقیم در قالب فایل‌های Word (با پسوند `.docx` و پشتیبانی کامل از زبان فارسی و راست‌چین) دانلود کند.

## ✨ ویژگی‌ها

- 🚀 **بسیار سبک و سریع:** ساخته شده با Node.js و Express.
- 💾 **بدون نیاز به دیتابیس پیچیده:** ذخیره‌سازی داده‌ها در فایل `JSON` (مناسب برای پروژه‌های کوچک و سریع).
- 📄 **خروجی Word استاندارد:** تولید فایل‌های `.docx` با استفاده از کتابخانه قدرتمند `docx`.
- 🇮🇷 **پشتیبانی از زبان فارسی:** تنظیم خودکار راست‌چین (RTL) بودن متون در فایل‌های خروجی.
- 🧩 **معماری ساده:** ساختار فایلینگ واضح برای توسعه و ارتقاء آسان.

## 🛠 پیش‌نیازها

برای اجرای این پروژه، باید موارد زیر روی سیستم شما نصب باشد:
- [Node.js](https://nodejs.org/) (نسخه 14 به بالا)
- npm (به همراه Node.js نصب می‌شود)
